ZERO-SHOT
    Мой промпт: К функции [] и её параметрам создай комментарий
    
    Ответ ИИ: Вот функция с добавленным комментарием в стиле godoc:
                    package piscine
                    // NRune возвращает n-ю руну (символ) в строке s.
                    // Нумерация рун начинается с 1 (то есть NRune(s, 1) вернёт первый символ строки).
                    // Если строка содержит меньше n рун, функция возвращает 0 (нулевое значение типа rune).
                    //
                    // Параметры:
                    //   s - строка, в которой нужно найти руну;
                    //   n - порядковый номер искомой руны (нумерация с 1).
                    //
                    // Возвращаемое значение:
                    //   rune - руна, найденная на позиции n, либо 0, если такой позиции не существует.
                    func NRune(s string, n int) rune {
                        i := 1
                        for _, r := range s {
                            if i == n {
                                return r
                            }
                            i++
                        }
                        return 0
                    }
                    Комментарий начинается с имени функции (`NRune ...`) — это стандартное требование godoc, чтобы документация корректно генерировалась и отображалась инструментами вроде `go doc`.
