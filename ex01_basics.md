INTRODUCTION
    В качестве функции на которой я буду пробовать разные формы промптов, я использовал функцию которую написал во время бассейна. Она просто выводит на экран цифры от 0 до 9. В коде использовался "for" цикл и коды символов ASCII для цифр от 0 до 9. На каждой итерации цикла вызывается z01.PrintRune(i), которая печатает соответствующий символ (руну).

DIRECT INSTRUCTION
    Мой промпт: Добавьте к этой функции внутристрочные комментарии, поясняющие назначение каждой строки: [Функция]
    
    Ответ ИИ: Вот функция с внутристрочными комментариями на русском языке:
                package main
                    // Импортируем пакет z01, содержащий функцию PrintRune для вывода символов
                    import (
                        "github.com/01-edu/z01"
                    )

                    func main() {
                        // Начинаем цикл: i — переменная типа rune (руна/символ), начинаем с 48 (код символа '0')
                        // Цикл выполняется, пока i <= 57 (код символа '9')
                        for i := rune(48); i <= rune(57); i++ {
                            // Выводим текущий символ (цифру) с помощью функции PrintRune из пакета z01
                            z01.PrintRune(i)
                        }
                        // После завершения цикла выводим символ перевода строки ('\n'),
                        // чтобы курсор перешёл на новую строку
                        z01.PrintRune('\n')
                    }
            Пояснения к логике:
                rune(48) — это код ASCII символа '0', а rune(57) — код символа '9'.
                Цикл for перебирает все руны от '0' до '9' включительно.
                На каждой итерации z01.PrintRune(i) выводит текущую цифру на экран.
                После окончания цикла отдельным вызовом выводится символ '\n', чтобы завершить строку переводом на новую.
            Итоговый вывод программы: 0123456789 с переводом строки в конце.

OPEN QUESTION
    Мой промпт: Что бы вы изменили в этой функции [Функция]

    Ответ ИИ: Вот что бы я улучшил в этой функции:
                1. Магические числа → используйте символьные литералы
                    Вместо rune(48) и rune(57) лучше писать '0' и '9' — это литералы типа rune в Go, но гораздо понятнее:
                            for i := '0'; i <= '9'; i++ {
                                z01.PrintRune(i)
                            }
                    Это убирает необходимость помнить ASCII-коды и делает код самодокументируемым — сразу видно, что цикл идёт по цифрам от '0' до '9'.
                2. Итоговый вариант
                            package main
                                import (
                                    "github.com/01-edu/z01"
                                )

                                func main() {
                                    for i := '0'; i <= '9'; i++ {
                                        z01.PrintRune(i)
                                    }
                                    z01.PrintRune('\n')
                                }
                Остальное — уже хорошо:
                    Логика верная: перебираются коды символов от 48 до 57, что соответствует символам '0'–'9' в ASCII.
                    Перевод строки в конце — аккуратно, через ту же функцию PrintRune.
                    Импорт и структура пакета минимальны и корректны.
                    Если нужно, могу подсказать, как переписать это через strconv или fmt, но с учётом того, что используется z01.PrintRune (это, похоже, задание из проекта 01/Zone01, где напрямую fmt использовать нельзя), текущий подход с рунами — правильный.
